## 🚀 About The Project

This is not just a static HTML site; it is a scalable web application. While the primary goal is to display data analysis case studies, the underlying architecture is built using Laravel to allow for future scalability (e.g., dynamic admin panel, blog integration, database-driven content).

### Key Features
- **Modern UI/UX:** Clean, responsive design built with **Tailwind CSS**.
- **Data-Centric Layout:** Specifically designed to highlight reports, dashboards, and case studies.
- **Scalable Architecture:** Codebase structured to easily switch from static mock data to a dynamic database system.
- **Professional Presentation:** Dedicated sections for "About Me", "Technical Skills", and "Featured Projects".
- **Optimized Performance:** Fast loading speeds using Laravel's efficient routing and blade templating engine.

## 📂 Project Structure (Key Files)

- `routes/web.php` - Contains the logic for serving the portfolio and mock data (scalable to Controller later).
- `resources/views/home.blade.php` - The main landing page with Hero, Skills, and Projects sections.
- `resources/views/layout.blade.php` - The master layout containing the Navbar and Footer components.
- `public/images/` - Stores profile images and project thumbnails.
